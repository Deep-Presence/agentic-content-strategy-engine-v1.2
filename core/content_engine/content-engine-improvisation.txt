Content Generation Engine (Pipeline) — Full Walkthrough
Purpose
Deep Presence helps B2B companies get cited in AI search results (Perplexity, ChatGPT, Claude, Gemini). The content engine is the final, revenue-generating pipeline. It takes everything the system has learned about a company — who they are (Pipeline 1: Research Artifacts) and where they're missing from AI citations (Pipeline 2: Gap Analysis) — and auto-generates optimized content designed to close those citation gaps.

In short: Pipeline 1 answers "Who is this company?", Pipeline 2 answers "Where are they invisible to AI?", and Pipeline 3 answers "What content should they publish to become visible?"

The 4-Stage Pipeline

[Stage 1] Strategic Planner
     ↓
[Stage 2] Content Workers (parallel)
     ↓
[Stage 3] Evaluator-Optimizer Loop
     ↓
[Stage 4] Human-in-the-Loop Review
Stage 1 — Strategic Planner
A single Claude Sonnet 4.5 call that reads all outputs from Pipelines 1 and 2:

Company context, persona profiles, style guide (from P1)
Gap report, generation spec, analysis JSON (from P2)
It identifies the highest-impact content opportunities — the queries where the company is semantically distant from what AI platforms are citing — and produces prioritized content briefs. Each brief specifies:

Target queries to optimize for
Content format (long blog, FAQ, pillar page, comparison, how-to)
Funnel stage, channel, priority score
Word count range, structural targets (min headers, lists, citations)
Key topics, angles, and competitor exemplars to learn from
Stage 2 — Content Workers (Parallel)
Each brief gets assigned to a worker that runs a 4-step chain concurrently (controlled by an asyncio.Semaphore, default 3 workers):

Step	Model	What it does
Outliner	Sonnet 4.5	Produces a structured section-by-section outline
Drafter	Sonnet 4.5	Writes the full article from the outline + style guide
Fact Enricher	Perplexity sonar-pro	Web-grounds the draft with real citations and statistics
Formatter	Haiku 4.5	Final polish, counts structural elements (headers, lists, stats, citations)
Every intermediate artifact is saved to disk for auditability and resumability.

Stage 3 — Evaluator-Optimizer Loop
Each piece of content goes through a 4-dimensional quality gate:

Dimension	Method	What it checks
Structural	Deterministic (regex)	Word count in range, enough headers/lists/citations, valid heading hierarchy, no empty sections
Semantic	Embedding similarity	Content embedding vs. target query embeddings — is the content actually about what it claims?
Style	LLM-as-Judge (Haiku 4.5)	Alignment with the company's writing style guide
Factual	LLM-as-Judge (Sonnet 4.5)	Factual accuracy, grounding, flags questionable claims
If any dimension fails, the system compiles feedback from all failed dimensions, sends it back to the drafter for revision, re-enriches with facts, re-formats, and re-evaluates. This loops up to max_revision_cycles times (default 2).

Stage 4 — Human-in-the-Loop Review
A LangGraph state machine presents each passing piece of content for human review:

Approve — content is finalized, written as final.md
Edit — editor notes are stored, content loops back for review
Reject — content is discarded
Supports auto_approve mode for batch/CI runs.

Observability
Every LLM call, evaluation score, and revision cycle is traced in Langfuse with a hierarchical span tree — session > pipeline > stage > worker > step > generation. This gives full visibility into token usage, timing, quality scores, and flagged claims.

def _check_paragraph_length(content, brief):
    """Check avg paragraph length matches target."""
    paragraphs = [p.strip() for p in content.markdown.split('\n\n') if p.strip() and not p.strip().startswith('#')]
    if not paragraphs:
        return True, "", {}
    avg_len = sum(len(p.split()) for p in paragraphs) / len(paragraphs)
    target = brief.structural_targets.avg_paragraph_length_words
    if target is None:
        return True, "", {"avg_paragraph_length": avg_len}
    tolerance = 0.4  # 40% tolerance
    passed = abs(avg_len - target) / target <= tolerance
    feedback = "" if passed else f"Avg paragraph length is {avg_len:.0f} words (target: ~{target}). {'Shorten' if avg_len > target else 'Expand'} paragraphs."
    return passed, feedback, {"avg_paragraph_length": avg_len, "target": target}

def _check_sentence_length(content, brief):
    """Check avg sentence length matches target."""
    import re
    sentences = re.split(r'[.!?]+', content.markdown)
    sentences = [s.strip() for s in sentences if len(s.strip().split()) > 3]
    if not sentences:
        return True, "", {}
    avg_len = sum(len(s.split()) for s in sentences) / len(sentences)
    target = brief.structural_targets.avg_sentence_length_words
    if target is None:
        return True, "", {"avg_sentence_length": avg_len}
    tolerance = 0.35
    passed = abs(avg_len - target) / target <= tolerance
    feedback = "" if passed else f"Avg sentence length is {avg_len:.0f} words (target: ~{target})."
    return passed, feedback, {"avg_sentence_length": avg_len, "target": target}

def _check_faq_section(content, brief):
    """Check FAQ section presence if required."""
    if not brief.structural_targets.has_faq_section:
        return True, "", {}
    has_faq = bool(re.search(r'#{1,3}\s*(FAQ|Frequently Asked Questions)', content.markdown, re.IGNORECASE))
    feedback = "" if has_faq else "FAQ section required but not found."
    return has_faq, feedback, {}

def _check_self_contained_ratio(content, brief):
    """Check what % of paragraphs are self-contained (make standalone claims)."""
    target = brief.structural_targets.target_self_contained_ratio
    if target is None:
        return True, "", {}
    paragraphs = [p.strip() for p in content.markdown.split('\n\n') if p.strip() and not p.strip().startswith('#')]
    if not paragraphs:
        return True, "", {}
    # Heuristic: paragraphs starting with pronouns referencing previous context are not self-contained
    referential_starters = ['this ', 'that ', 'these ', 'those ', 'it ', 'they ', 'such ']
    self_contained = sum(1 for p in paragraphs if not any(p.lower().startswith(s) for s in referential_starters))
    ratio = self_contained / len(paragraphs)
    passed = ratio >= target
    feedback = "" if passed else f"Self-contained ratio {ratio:.2f} is below target {target}. Reduce referential paragraph openings."
    return passed, feedback, {"ratio": ratio, "target": target}

Enricher gets: draft + key topics + domain context (minimal)
Formatter gets: enriched content + style guide (FULL) + structural targets
Each stage should get exactly what it needs — no more, no less.

B. Two-Pass Drafting for Long Content
For pillar pages (2500-4000 words), a single Sonnet call producing 4000 words will degrade in quality. Split into:

Section-by-section drafting (one call per 2-3 sections)
Coherence pass (one call to ensure transitions and narrative flow)
C. Parallel Evaluation → Targeted Revision
Instead of sending all failed feedback back to the drafter:

If only structural fails → use the formatter to restructure (cheaper, faster)
If only style fails → use a style-specific revision pass
If only factual fails → re-run enricher with specific claims to verify
If semantic fails → that's a fundamental content problem → re-outline + re-draft
D. Increase Revision Cycles for Pillar Pages
Default max_revision_cycles=2 may not be enough for complex, long-form content. Consider:

short_faq: 1 cycle
